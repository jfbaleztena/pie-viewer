# Quick Start

## 5 minutos para tener la app funcionando

1. **Entorno**
```bash
cd pie-viewer
python -m venv venv
# Windows: .\venv\Scripts\activate
# Linux/Mac: source venv/bin/activate
pip install -r requirements.txt
```

2. **Ejecutar**
```bash
python -m src.main
```

3. **Cargar STL**
- Ctrl+O → Seleccionar archivo .stl
- O: Archivo → Abrir STL

4. **Explorar**
- Click derecho + drag = Rotar
- Rueda mouse = Zoom
- Botones derechos = Vistas predefinidas
