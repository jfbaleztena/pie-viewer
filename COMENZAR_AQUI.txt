4. ACTIVAR ENTORNO
   
   .\venv\Scripts\activate

================================================================================
  USO DE LA APLICACIÓN
================================================================================

CARGAR UN ARCHIVO STL:
  1. Menú → Archivo → Abrir STL
  2. O presionar: Ctrl+O
  3. Seleccionar un archivo .stl de tu pie

VER DIFERENTES VISTAS:
  - Panel derecho: 7 botones grandes con vistas estándar
  - Anterior (Punta), Posterior (Talón), Dorsal (Arriba), Plantar (Abajo)
  - Medial (Interno), Lateral (Externo), Isométrica

INTERACTUAR CON EL MODELO:
  - ROTAR: Click derecho + arrastrar el mouse
  - ZOOM: Rueda del mouse (arriba/abajo)
  - PAN: Click central + arrastrar el mouse

INFORMACIÓN DEL MODELO:
  - Barra inferior: Número de vértices y triángulos cargados
  - Está validado automáticamente

================================================================================
  TROUBLESHOOTING
================================================================================

PROBLEMA: "ModuleNotFoundError: No module named 'PyQt6'"
SOLUCIÓN: pip install PyQt6==6.7.1

PROBLEMA: "ModuleNotFoundError: No module named 'vtkmodules'"
SOLUCIÓN: pip install VTK==9.3.0

PROBLEMA: La ventana no aparece
SOLUCIÓN:
  1. Verifica que (venv) esté visible en la terminal
  2. Intenta de nuevo: python -m src.main
  3. Si aún no funciona, reinstala: pip install -r requirements.txt

PROBLEMA: "Error: Archivo no encontrado"
SOLUCIÓN: Verifica que el archivo .stl exista y tenga la extensión correcta

PROBLEMA: Los tests fallan
SOLUCIÓN: Asegúrate de estar en el directorio pie-viewer y que el venv esté activado

================================================================================
  COMANDOS ÚTILES
================================================================================

# Activar el entorno virtual
.\venv\Scripts\activate

# Desactivar el entorno virtual
deactivate

# Ejecutar la aplicación
python -m src.main

# Ejecutar todos los tests
python -m pytest tests/ -v

# Ejecutar solo tests de mesh_loader
python -m pytest tests/test_mesh_loader.py -v

# Ejecutar solo tests de integración
python -m pytest tests/test_integration.py -v

# Ver cobertura de tests
python -m pytest tests/ --cov=src

# Salir de la aplicación
Ctrl+Q o cerrar la ventana
